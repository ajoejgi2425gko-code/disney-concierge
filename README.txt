ディズニー攻略コンシェルジュ

【公開方法】
1. ZIPを解凍します。
2. GitHubで新しいPublicリポジトリを作成します（例：disney-concierge）。
3. このフォルダ内の7ファイルを、フォルダごとではなくリポジトリ直下にアップロードします。
4. Settings > Pages > Build and deployment で「Deploy from a branch」を選びます。
5. Branchを main、Folderを /(root) にして Save します。
6. 公開後、https://ユーザー名.github.io/disney-concierge/ でアクセスします。

【仕組み】
このアプリはAIへの相談プロンプトを端末内で生成します。AIサービスへ自動送信せず、利用者が文章をコピー・共有してChatGPT、Gemini、Copilot等に貼り付けます。運営者のAI APIキーやAPI従量課金は不要です。

【オフライン】
初回アクセス後はアプリ画面とプロンプト生成をオフラインでも利用できる場合があります。AIサービスで回答を得るにはインターネット接続が必要です。外部フォントはオンライン時のみ読み込まれます。

【重要】
施設運営、営業時間、ショー、DPA、スタンバイパス等は変更されます。AIの回答を鵜呑みにせず、東京ディズニーリゾート公式サイト・公式アプリで必ず最新情報を確認してください。
